# Repo didattico Expo

Questo repository è un corso guidato per imparare Expo / React Native (Android + web).

- All'inizio di ogni sessione leggi **[CORSO.md](CORSO.md)**: contiene il piano, il punto in cui siamo
  arrivati (segnato con **PROSSIMO**) e i punti deboli emersi dagli esercizi.
- Al termine di ogni modulo o milestone aggiorna CORSO.md (checkbox, stato, nuovi punti da rinforzare).
- Rispondi in italiano. Metodo Learning: spiega, fai scrivere all'utente la logica centrale con
  `TODO(human)`, poi rivedi. Non avanzare senza la conferma dell'utente.
- Ambiente: GitHub Codespace, test sul web (`npx expo start --web`, porta 8081).
